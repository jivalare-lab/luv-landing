# LUV landing

Single-page recruitment site for Loyola University Ventures, based on the November 16, 2026 concept packet from Jey Miguez. The source of the page is HTML and CSS. The supplied PNG was used as a visual reference, not as the page itself.

## Current scope

The page explains LUV and its Connect, Collab, Create invitation. Event-update signup is intentionally not active because the packet does not provide a mailing list, approved form destination, data owner, or privacy language. No visitor email is collected or stored.

## Local check

Run `node verificar.js` and open `index.html` in a browser.

## Before activating signup

The club should identify the list owner and platform, confirm the consent and unsubscribe wording, and test submission, storage, confirmation, and removal end to end. Signup for updates must remain distinct from formal club membership.
